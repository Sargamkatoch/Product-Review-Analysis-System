# Product Review Sentiment Analysis

> A Machine Learning and Deep Learning based sentiment analysis system for classifying product reviews into positive or negative sentiments.

---

## 📌 Overview

The Product Review Sentiment Analysis project focuses on analyzing customer reviews and determining whether the sentiment expressed is positive, negative, or neutral.

This project uses multiple Machine Learning and Deep Learning models to compare performance and improve sentiment classification accuracy.

The system is trained using product review datasets and can help businesses understand customer opinions, improve products, and analyze user feedback efficiently.

---

## 🚀 Features

* Sentiment classification of product reviews
* Text preprocessing and cleaning
* TF-IDF vectorization
* Machine Learning models implementation
* Deep Learning models implementation
* Transfer Learning using BERT/DistilBERT
* Model comparison using evaluation metrics
* Accuracy, Precision, Recall, and F1-score analysis
* Cross-domain sentiment transfer learning

## 📊 Dataset Information

### Training Dataset

* Amazon Reviews 2018 Electronics Dataset

### Fine-Tuning Dataset

* Flipkart Reviews 2023 (Mobiles & Laptops)

The project uses a cross-domain transfer learning approach where models are first trained on Amazon reviews and later fine-tuned on Flipkart reviews.
